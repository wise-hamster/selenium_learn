----------------------------------------------------------
            Общая информация - wd_interface.py
----------------------------------------------------------
webdriver.Chrome() - запуск веб-драйвера.
Chrome() - запуск Chrome
.get() - переход к ссылке
.find_element () - поиск элемента
.back() - клик назад
.forward() - клик вперед
.refresh() - перезагрузка страницы
.title - значение тайтла
.close() - закрыть окно
.quit() - остановить драйвер.
.current_url - текущий URL
----------------------------------------------------------

----------------------------------------------------------
.switch_to.alert - переход к alert
.switch_to.alert.accept() - клик по ОК
.switch_to.alert.dismiss() - клик по cancel
.switch_to.alert.send_keys() - введение текста

x,y, height, widht

----------------------------------------------------------
            Локаторы
----------------------------------------------------------
.send_keys(Keys.ARROW_DOWN) - управление с помощью клавиатуры
.find_element() - поиск элемента по локатору
.find_elementS() - поиск элементов по локатору

По ID (By.CSS_SELECTOR, '#input-example') 
По классу  (By.CSS_SELECTOR, '.my-class')
По тегу (By.CSS_SELECTOR, 'button')
По атрибуту (By.CSS_SELECTOR, "a[href='https://example.com']")

| Назначение                                      | CSS-селектор    | Пример Python с Selenium                                       |
| ----------------------------------------------- | --------------- | -------------------------------------------------------------- |
| Выбор непосредственного дочернего               | parent > child  | driver.find_element(By.CSS_SELECTOR, 'div > p')                |
| Выбор элементов, у которых класс содержит слово | [class~='word'] | driver.find_element(By.CSS_SELECTOR, "[class~='active']")      |
| Выбор по атрибуту, начинающемуся с              | [attr^='value'] | driver.find_element(By.CSS_SELECTOR, "input[id^='user']")      |
| Выбор по атрибуту, заканчивающемуся на          | [attr$='value'] | driver.find_element(By.CSS_SELECTOR, "a[href$='.pdf']")        |
| Выбор по конкретному атрибуту                   | [attr='value']  | driver.find_element(By.CSS_SELECTOR, "input[type='password']") |
